**Status:** Prototype stage - initial prints completed, design being refined.

A 49:1 balun wound on a FT240-43 toroid is mounted to the cover, with BNC connector in the center. An M5 ground bolt is also attached to the cover.

## Printed Parts
- 1x Frame
- 1x Drum (spool)
- 1x Cap
- 2x Plain Pillars
- 1x Eyelet Pillar (has wire guide)
- 1x Pillar Rim (optional)

## Hardware List
- **Axle:** M8 x 65mm stainless bolt + M8 hex nut
- **Bearing:** 608zz (standard skateboard bearing)
- **Cover Bolts:** 3x M4 x 16mm stainless machine screws + 3x M4 nuts
- **Pillar Bolts:** 6x M3 x 12mm stainless machine screws + 6x M3 nuts
- **Feedpoint:** 1x BNC Bulkhead (female-to-solder) + 1x M5 bolt/wingnut for ground
