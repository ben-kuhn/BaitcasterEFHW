**Status:** Prototype stage - initial prints completed, design being refined.

A 49:1 unun wound on a FT240-43 toroid is mounted to the cap, with BNC connector in the center. An M5 ground bolt provides counterpoise connection.

- **Bearing:** 608zz (standard skateboard bearing)
- **Cap Bolts:** 3x M4 x 16mm stainless machine screws + 3x M4 nuts
- **Rim Bolts:** 3x M4 x 12mm stainless machine screws + 3x M4 nuts (optional)
- **Feedpoint:** 1x BNC Bulkhead (D-flat style) + 1x M5 bolt/wingnut for ground
